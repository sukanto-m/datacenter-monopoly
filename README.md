# ⚡ Data Center Tycoon ⚡

A browser-based Monopoly game themed entirely around data centers, cloud infrastructure, and tech operations.

![Game Preview](screenshot.png)

## 🎮 Play Now

Just open `index.html` in your browser. No build process, no dependencies, no servers needed.

```bash
git clone https://github.com/yourusername/datacenter-monopoly.git
cd datacenter-monopoly
open index.html  # or just double-click the file
```

## 🏢 Features

- **40 Properties** themed around real infrastructure:
  - Edge nodes (Seattle, Portland)
  - Colocation facilities (Chicago, Ashburn, Dallas)
  - AWS, Azure, and GCP cloud regions
  - Hyperscale data centers (Singapore, Tokyo, Sydney)
  - Quantum data centers (Zurich, Amsterdam, Frankfurt)
  - AI compute clusters (London, Paris)

- **Tech-themed gameplay:**
  - Add server racks instead of houses (costs $200 per upgrade)
  - Pay bandwidth taxes instead of luxury tax
  - Land on "DDoS Attack" instead of jail
  - Get hit by "Ransomware" instead of "Go to Jail"
  - Network outages instead of Community Chest
  - Utilities: Tier-1/2/3 Providers, Power Grid, Cooling Systems, Fiber Links

- **Full game mechanics:**
  - 2-player turn-based gameplay
  - Property ownership and rent collection
  - Server upgrades (Rack → 2 Racks → 3 Racks → 4 Racks → Full Cluster)
  - Real-time game log
  - Click any property to see detailed stats

## 🎯 How to Play

1. Roll the dice to move around the board
2. Buy data centers when you land on available properties
3. Add servers to increase rent (max 5 levels)
4. Collect rent when opponents land on your infrastructure
5. Avoid DDoS attacks and bandwidth taxes
6. Bankrupt your opponent to win!

## 🛠️ Tech Stack

Pure vanilla JavaScript, HTML, and CSS. No frameworks, no build tools, no nonsense.
